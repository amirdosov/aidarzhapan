# АйдарЖапан шежіресі

Сайт полного родословного древа: 114 человек, 20 поколений,
от Адая (1435–1549) до правнуков 2022 года.

Шежіре собрал **Досов Алпамыс Орынбасарұлы**. Сайт — способ показать
эту работу семье так, чтобы её было удобно читать с телефона.

## Доступ

Сайт открывается личной ссылкой:

```
https://amirdosov.github.io/aidarzhapan/#c69mys
```

Кто в ней назван, тот здесь и «я»: лента строится от него, родство
считается от него, выбирать ничего не нужно. Без ссылки виден только
порог. Ссылку раздаёт не сайт, а родня — в карточке каждого живого
есть «{есім} үшін сілтеме», её отправляют в WhatsApp.

Замком это не является: репозиторий открытый, `data/people.js` читается
и без сайта. Это именная дверь, а не защита.

## Локальный просмотр

```bash
python -m http.server 8765
```

Локально войти можно так же — `http://localhost:8765/#c69mys`.

## На телефон, приложением

Шежіре ставится значком на экран: открывается без браузера и читается
без интернета — в дороге, в ауле, в самолёте.

- **Android:** внизу страницы кнопка «Қосымша ретінде орнату».
- **iPhone:** «Поделиться» → «На экран „Домой“».

Значок запускает шежіре сразу от вашего имени: личный ключ из ссылки
уходит в адрес запуска приложения. На iPhone у приложения своя память,
и ссылка из WhatsApp откроется в Safari, а не в значке, — поэтому внутри
приложения на пороге есть поле, куда эту ссылку вставляют один раз.

Иконки собираются из той же метки, что стоит в шапке сайта:

```bash
python tools/icons.py
```

## Фотографии

Скиньте снимки в папку по `id` человека и выполните:

```bash
python tools/photos.py
```

Скрипт сам развернёт по EXIF, вычистит метаданные включая GPS, ужмёт,
переименует, сделает превью и соберёт список.
Подробности — [assets/photos/README.md](assets/photos/README.md).

## Что это не заменяет

Сайт близкой семьи (`shezhire`) продолжает работать отдельно и здесь
не затрагивается. Этот проект — про весь род.
