# План работ

Что известно об исходных данных — в [DATA.md](DATA.md).
Решения по интерфейсу — в [DESIGN.md](DESIGN.md).

## Принципы

- **Статика без сборки.** Три-четыре файла, открываются как есть, деплой
  на GitHub Pages из ветки `main`, папка `/`. Как на текущем сайте —
  проверено, работает, обновление живёт минуту.
- **Текущий сайт не трогаем.** `shezhire` остаётся как есть и продолжает
  работать по своему адресу.
- **Данные отдельно от кода.** Всё про людей — в `data/`, интерфейс о них
  ничего не знает заранее.
- **Каждый шаг проверяем на телефоне**, а не только на мониторе.

## Фотографии

Механика переносится с текущего сайта без изменений и работает
с первого дня:

```
assets/photos/<id>/01.jpg, 02.jpg, ...
python tools/photos.py
```

Скрипт разворачивает по EXIF, чистит метаданные включая GPS, ужимает
до 1600 px, переименовывает, делает превью 240 px и собирает
`assets/photos.js`. Первое фото становится аватаром, остальные — галереей
с полноэкранным просмотром. Подробности — `assets/photos/README.md`.

Для 139 человек это тем более важно: фотографии будут появляться
постепенно, годами, и добавление не должно требовать программиста.

## Работа с гитом

Ветка `main` — то, что опубликовано. Каждый законченный кусок — отдельный
коммит с внятным сообщением по-русски. Крупные этапы помечаем тегами
(`v1-lenta`, `v2-poisk`), чтобы можно было откатиться к рабочему состоянию.

Что коммитим: код, данные, документацию, фотографии, исходный xlsx.
Что не коммитим: временные файлы, `.claude/`, мусор ОС — см. `.gitignore`.
