# Фотографии

Статический хостинг не отдаёт список файлов в папке, поэтому его надо
объявить заранее. Этим занимается скрипт.

## Как добавить

1. Создайте папку по `id` человека из `assets/data.js` и просто скиньте туда
   снимки — с любыми именами, прямо из телефона или WhatsApp:

```
assets/photos/amirzhan/
assets/photos/albina/
```

2. Выполните:

```bash
python tools/photos.py
```

Скрипт сам:

- развернёт снимки по EXIF и **вычистит метаданные, включая GPS-координаты**;
- ужмёт до 1600 px по длинной стороне (телефонные 2–3 МБ станут ~200 КБ);
- переименует в `01.jpg`, `02.jpg`, ... по алфавиту исходных имён;
- сделает превью 240 px в подпапке `thumbs/` — их грузят аватар и миниатюры,
  чтобы в кружок 56 px не тянулся полноразмерный снимок;
- перепишет `assets/photos.js`.

Первое фото становится аватаром. Чтобы поменять порядок или главное фото,
переименуйте файлы (`03.jpg` → `00.jpg`) и запустите скрипт снова.

Скрипт можно гонять сколько угодно раз: уже обработанные файлы просто
пересохранятся, ничего не сломается.

## Без скрипта

Если фото одно-два, можно прописать список руками в `assets/data.js`:

```js
photos: ["assets/photos/amirzhan/01.jpg"]
```

или совсем коротко:

```js
photo: "assets/photos/amirzhan.jpg"
```

Список в `data.js` имеет приоритет над собранным скриптом.

## Не забудьте про кеш

После добавления фото поднимите версию в `index.html` (`?v=7` → `?v=8`)
у всех файлов в `assets/` — иначе у тех, кто уже открывал сайт,
браузер возьмёт старый список из кеша.

## Что будет, если файла нет

Ничего не сломается: в аватаре останется первая буква имени,
а битая миниатюра сама уберётся из галереи.
